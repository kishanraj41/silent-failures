# Contributing

Thank you. Two kinds of contribution help most:

1. **Corrections.** If you were involved in an incident here, or know the source better, open an issue. Factual corrections are merged first.
2. **New incidents.** Open a pull request that adds one row to `data/incidents.csv` (harm shown) or `data/mechanisms.csv` (mechanism only), following `docs/DATA_DICTIONARY.md`. Include a dated public source and how the failure was detected.

Please don't add private incidents, internal company data, or anything identifying a private individual who hasn't published about it themselves.
